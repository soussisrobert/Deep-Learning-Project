`uav123_got10k.json`: start/end frame of every UAV123 and UAV20L sequence (several annotated
sequences are slices of one video, e.g. bird1_1, bird1_2). Copied unchanged from the GOT-10k
toolkit, https://github.com/got-10k/toolkit/blob/master/got10k/datasets/uav123.json (MIT licence).
Used by tools/prepare_uav.py when no configSeqs*.m file is available.
