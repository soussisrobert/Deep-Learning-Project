# Wave6 guarded B2 execution — BLOCKED / NOT APPROVAL READY

## Decision and scope

Wave6 implements executable additive safeguards rather than repeating the Wave5 preparation-only audit. **No authentic-image backward/SGD, GPU compute experiment, tracking benchmark, B0/B1 tuning, full B2 training or R1 was run. No real human grant or pilot proposal was approved or fabricated.**

Ordinary desktop applications are not automatically killed or waved through a process-name allowlist. RAM passes at that instant; **ownership ambiguity alone remains the current blocker**. Its native [SMI XML](<../artifacts/wave6-lease-validation/native-smi-002.xml>) comes from the absolute System32 producer with stable binary hash.

The conditional new-pilot-proposal portion is deliberately **not issued**: the user required B1–B7 to pass first. There is therefore no new approvable experiment ID, proposal SHA, expiry, human ACK or runnable approved command to present. The old [Wave5 draft](../artifacts/wave5-preparation/PROPOSAL-001/UNAPPROVED-PROPOSAL.json) and its expiry remain historical, unapproved and byte-identical. ## Executable changes

All scientific execution changes are isolated under [Wave6](../src/hift_research/wave6/__init__.py) and the new [guarded bootstrap](../scripts/run_b2_guarded.py). The 29 frozen executing files, frozen pilot config, original optimizer/loss/sampling/rejection mathematics, source datasets/checkpoints and immutable upstream remain unchanged.

1. **External inclusive time and Windows containment.** [Ledger](../src/hift_research/wave6/ledger.py), [supervisor](../src/hift_research/wave6/supervisor.py) and [native Job control](../src/hift_research/wave6/windows_job.py) use the original bootstrap monotonic origin. Native `PROC_THREAD_ATTRIBUTE_JOB_LIST` atomically contains a suspended process before execution; kill-on-close and descendant accounting prevent a scheduled uncontained child. Cleanup gets reserved time, not a new timeout. Durable one-shot timing begins before expensive preflight. Independent parent watchdogs bound preflight, reservation I/O, supervisor work and outer cleanup; a bootstrap watchdog also bounds earlier hashing. Overshoot is a failure, not a modeled success.
2. **Exact human-ACK envelope.** [Authorization](../src/hift_research/wave6/authorization.py) binds complete proposal bytes and canonical digest, scientific scope, resources, argv/cwd/output, input/source/init maps, physical GPU, expiry and permanent one-use claim. The ACK requires exact text plus concrete user-message/session transport references. These are **not cryptographic human-identity proof**; deliberate operator/administrator tampering and pre-Python startup hooks are outside the trust boundary. Self-approved booleans and old grant formats cannot authorize the new path.
3. **Operational guards.** [Runtime checks](../src/hift_research/wave6/runtime.py) run after every actual backward, before clipping, immediately before SGD, after SGD and at commit/checkpoint/final boundaries. They check finite parameters/gradients/norms/momentum, exact optimizer parameter order and epoch0 options, original trainable flags, frozen backbone/full BN state and modes, device identity, resources and source/data integrity. Real execution uses native probes: peak host RSS <=8 GiB, available host RAM >=4 GiB, and CUDA reserved <=80% of physical VRAM; allocated/reserved consistency is checked. UUID is checked before model/optimizer construction.
4. **Typed input failures.** Real geometry rejection remains exactly `no_available_target_source_support` or `template_target_visible_in_negative_search`; no refill or population change. Decode/shape/dtype/nonfinite/mask/identity/hash corruption is fatal. The original NCHW bridge is retained. FP32 image/offset hashes and lossless class-label hashes are checked; fractional FP64 target hashes are not falsely roundtripped after FP32 conversion.
5. **Unchanged scientific core.** [Observed adapter](../src/hift_research/wave6/adapter.py) invokes the original serial controller, original backward, original once-per-window clipping and original SGD. Detached telemetry adds no forward or RNG draw. The narrow in-memory legacy-constructor bridge is available only inside the already verified worker; it never writes a fake legacy grant or changes frozen authorization flags. Entire corrected grader remains trainable according to the frozen factory; backbone parameters may remain in the original optimizer group but cannot acquire gradients/change.
6. **Durable evidence and taint.** [Hash-chained fsynced journal](../src/hift_research/wave6/telemetry.py) records attempt IDs/classes, rejections, global denominators, loss components, micro backward, clip norms, LR/resources, commit/checkpoint and failures. Only an incomplete final tail is recoverable; a complete corrupt record fails. The parent independently rehashes the last published checkpoint and finalizes its ledger only after receipt publication and lease cleanup. A post-step or commit-logging failure can leave physical live state mutated: it is explicitly **tainted/unpublished**, not falsely rolled back or published as a successful commit. Earlier atomic checkpoint bytes remain intact.
7. **Actual Windows GPU lease.** [Lease implementation](../src/hift_research/wave6/lease.py) combines a host-global UUID mutex with durable authorization/PID/Windows creation-time/nonce identity. A strict direct-child proof uses the actual base interpreter plus the verified venv-launcher environment, preserving the approved logical Python/venv without accepting an intermediate redirector as lease owner. Stale/partial/uncertain ownership is never automatically stolen. Unproved tree cleanup retains blocking evidence rather than advertising a safely released device.

## Supported entry and import integrity

[The guarded entry](../scripts/run_b2_guarded.py) is the only **supported/authorized normal production route** for a future Wave6 pilot. The historical [legacy launcher](../scripts/run_b2_pilot.py) remains mechanically present because frozen files were not modified; this is not a sandbox preventing arbitrary Python or deliberate legacy invocation. The new exact envelope is incompatible with the legacy grant schema.

The reviewed bootstrap removes script/cwd/PYTHONPATH stdlib shadowing before stdlib imports, verifies exact project source closure/bytes before mutable project imports, and rejects project native/sourceless shadows and aliases. A project-only checked `SourceFileLoader` reads each source once, checks its approved SHA256 and compiles those same bytes, including explicit file-spec imports. It never reads project bytecode; the worker verifies the installed policy/map digest before Torch. This closes stale same-size/same-timestamp pycache and source-read/compile races without recompiling every trusted Torch dependency. Operator-installed interpreter/site/dependency startup and dependency caches are an explicitly trusted environment boundary—not a complete hermetic-Python or administrator-resistant claim.

The synthetically testable entry is structurally isolated: dedicated TEMP namespace, CPU only, at most 2 updates/32 attempts/2 windows/30 seconds, explicitly synthetic ACK transport role and exact random-only `SyntheticCandidateDataset`. Counterfactual resource probes in those disposable fixtures are labeled synthetic and are **never used by authentic execution**. No authentic images are selected by that branch.
